# Claude Code Notes

A practical reference for engineers using Claude Code — from safe first sessions through customization, automation, integrations, plugins, and troubleshooting.

The learning content starts at [`docs/index.md`](docs/index.md).

## Local preview

```bash
uv sync
uv run mkdocs serve
```

Open the local URL printed by MkDocs. A successful preview reloads after a note is saved.
